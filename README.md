## 英语包说明（重要）

英语包不是重做的，而是把原项目 `考研英语大作文背诵`（v1.3.10）**原样嵌入**壳里：卡片数据、六大方面分组、图表词汇、替换升级、SRS 调度、倒计时全部保持原样，只在末尾注入一段 `#packBridge` 做三件事：

1. 隐藏包内自己的底栏，改用壳的底栏
2. 把「今日 / 词库 / 测试」映射到包内 `#/`、`#/lib`、`#/test`，把「我的」交给壳抽屉
3. 从 `localStorage['ky_zw_v1']` 读出已掌握卡片数，上报给壳做进度统计

独立打开 `packs/en.html` 时行为与原来完全一样，不受影响。

## 路由（hash，重要）

线上壳经 CDN `aka.doubaocdn.com/s/<id>` 会 302 到签名域，**query 会被丢弃、fragment 会保留**，所以路由全部走顶层 hash，不用 query：

- `#book=<id>&tab=<t>` 进入某科并指定标签
- `#view=study` 学习汇总页
- 空 hash 书库
- 邀请链接 `#ref=<邀请码>`

顶层 hash 与 iframe 内部各自的 hash 完全独立，互不影响。包内切换标签用 `history.replaceState` 回灌，不新增历史条目。

## 加载与容错

- iframe `load` 后等待包发 `ready`，2 秒超时未收到（中断/错误页）判定为失败
- 失败时遮罩显示红色感叹号与「重新加载」，重试会删除坏帧并按当前 hash 重建，学习进度不丢
- 同时只保留最近 2 个科目帧，其余自动回收，控制内存

## 活动规则（已实现）

- 签到：每天 1 次，累计 7 天送 3 天会员并开新一轮；签到得的抽奖次数**仅当天有效**，零点清零
- 邀请：朋友注册 → +1 次抽奖，**可累积**，不清零
- 抽奖：8 格转盘，权重可配；扣次数先扣当天池，再扣累积池；「再来一次」在本次所用池回补，不串池
- 会员以 `vipUntil` 为唯一基准，启动按日期反算剩余、过期归零，加会员同时更新天数与到期日
- 活动开关：`ST.act.on=false` 时抽奖卡灰化显示「暂停中 · 未开放」，点击只提示，不打开转盘；已抽到的不收回
