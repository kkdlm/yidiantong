# 法硕一点通 · 一站上岸

2027 法硕非法学。书库壳 + 分科内容包，一个入口进各科，会员、签到、抽奖、邀请、卡密都在这一层。

站点：https://kkdlm.github.io/yidiantong/

## 科目

| 科目 | 包 | 线上体量 | 内容 |
|---|---|---|---|
| 法制史 | `packs/fz.html` | 6.73 MB | 169 考点 · 3561 条 · 断代史 / 专题史 |
| 政治 | `packs/zz.html` | 1.14 MB | 100 考点 · 596 题 |

| 法理学 | fl | 74 KB | 框架 · 考点卡片 |
| 宪法 | xf | 52 KB | 口说 · 选举与备案 |

政治「真一页」不并入书库。五科包都取自内容 CDN；`packs/` 里只留三个早期快照供对照。

## 发布

工作流 `.github/workflows/sync-packs.yml` 每次先拉线上壳，校验版本号与各包编号，再连同后台、图标组装站点目录，发 Pages。线上不读仓库里的 `index.html`；仓库里那份与 `shell.html` 是早期本地预览副本。

## 路由

壳经 CDN 转发会丢 query、保留 fragment，所以路由走顶层 hash：

- `#book=<id>&tab=<t>` 进某科并定位标签
- `#view=study` 学习汇总
- `#ref=<邀请码>` 邀请
- 空 hash 书库

## 结构

```
build_packs.py     给法制史、政治包注入壳协议
build_en_pack.py   给英语包注入桥接层
packs_src/         英语原项目副本
packs/             构建产物快照
admin/             管理后台
```

## 加载

iframe 载入后等包发 `ready`，2 秒未到则显示重载；重试重建帧，学习进度不丢。最多同时保留两个科目帧。

## 壳协议

- 包 → 壳：`ready(tabs)`、`stat(pct, items)`、`askMe`、`tab(id)`、`toast(msg)`
- 壳 → 包：`theme(night, fz, vip)`、`tab(id)`

包内「我的」一律走壳里那一份。

## 活动

- 签到每天一次，累计 7 天送 3 天会员；签到得的抽奖次数当天有效，零点清空
- 邀请一位新用户加一次抽奖，可累积
- 抽奖先扣当天池、再扣累积池，「再来一次」回补本次用的池
- 会员以到期日为准，启动时按日期反算
- 活动开关关闭时抽奖卡置灰，已抽到的不收回
