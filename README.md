# 法硕一点通 · 一站上岸

2027 法硕非法学。一个书库壳加若分科内容包，从一个入口进各科，会员、签到、抽奖、邀请、卡密都在这一层。

站点：https://kkdlm.github.io/yidiantong/

政治「真一页」不并入书库。

## 发布

工作流 `.github/workflows/sync-packs.yml` 每次先拉线上的壳与包，校验版本号和内容包编号，再连同后台、图标一起组装站点目录，最后发 Pages。仓库里只放源与产物快照，线上从不直接读仓库里的 `index.html`。

`index.html` 与 `shell.html` 是早期本地预览副本，已不再跟随后续发布，仅供对照。

## 路由

壳经 CDN 转发时会丢 query 但保留 fragment，所以路由全走顶层 hash：

- `#book=<id>&tab=<t>` ：进入某科并定位到某个标签
- `#view=study` ：学习汇总页
- `#ref=<邀请码>` ：邀请入口
- 空 hash ：书库

## 结构

```
build_packs.py       给法制史、政治包注入壳协议，输出到 packs/
build_en_pack.py     给英语包注入桥接层，输出到 packs/en.html
packs_src/           英语原项目副本
packs/               构建产物快照
admin/               管理后台
```

## 加载

iframe 载入后等包发 `ready`，2 秒没等到就判失败，显示重载按钮；重试会重建帧，学习进度不丢。同时最多保留两个科目帧。

## 壳协议

- 包 → 壳：`ready(tabs)`、`stat(pct, items)`、`askMe`、`tab(id)`、`toast(msg)`
- 壳 → 包：`theme(night, fz, vip)`、`tab(id)`

包内的「我的」一律走壳的同一份。

## 活动

- 签到每天一次，累计 7 天送 3 天会员；签到得的抽奖次数当天有效，零点清空
- 邀请一位新用户加一次抽奖，可累积
- 抽奖扣次数先扣当天池、再扣累积池，「再来一次」回补到本次用的池
- 会员以到期日为准，启动时按日期反算
- 活动开关关闭时抽奖卡置灰，已抽到的不收回
